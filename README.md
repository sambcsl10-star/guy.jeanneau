# guy.jeanneau - Mi Sitio Web Personal

¡Bienvenido a mi sitio web personal! Este es mi espacio para compartir fotos, videos y momentos especiales de mi vida.

## 📸 Características

- **Galería de Fotos**: Comparte tus mejores momentos
- **Sección de Videos**: Incorpora tus videos favoritos
- **Sobre Mí**: Cuéntale a los visitantes quién eres
- **Formulario de Contacto**: Permite que otros se comuniquen contigo
- **Diseño Responsivo**: Se ve perfectamente en móvil y computadora
- **Tema Azul Moderno**: Diseño limpio y profesional

## 🎨 Colores Principales

- Azul primario: #0066cc
- Azul oscuro: #004499
- Azul claro: #0088ff
- Gris claro: #f5f7fa

## 📝 Cómo Personalizar

### Cambiar fotos
1. En `index.html`, reemplaza las URLs de placeholder con tus propias imágenes
2. Usa la ruta: `<img src="tu-imagen.jpg" alt="Descripción">`

### Agregar videos de YouTube
1. Copia el ID del video de YouTube
2. Reemplaza el ID en el iframe: `https://www.youtube.com/embed/ID-DEL-VIDEO`

### Modificar colores
1. Abre `styles.css`
2. Busca los códigos de color (#0066cc, #004499, etc.)
3. Reemplázalos con tus colores preferidos
